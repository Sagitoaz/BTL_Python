## 🚀 How Personalization Works

### Data Flow

```
1. User types code → Extension requests completion
                     ↓
2. Extension sends X-User-ID header → Backend
                     ↓
3. Backend calls profiler.get_style_hints(user_id)
                     ↓
4. Profiler loads user profile from JSON
                     ↓
5. If ≥3 samples: generate style hints string
                     ↓
6. Inject hints into LLM prompt → Groq API
                     ↓
7. Return personalized completion → Extension
                     ↓
8. User accepts → Extension calls btl.trackAcceptance
                     ↓
9. Extension sends POST /feedback/completion
                     ↓
10. Backend analyzes code → Updates profile
                     ↓
11. Next completion uses updated profile!
```

### Pattern Detection Algorithms

#### Indent Size (GCD Method)
```python
# Extract all line indents
indents = [len(line) - len(line.lstrip()) for line in lines if line.strip()]
# Find GCD of all indents
gcd = reduce(math.gcd, indents)
# Most common indent size wins
indent_size = most_common([i for i in indents if i > 0])
```

#### Quote Preference
```python
single_count = len(re.findall(r"'[^']*'", code))
double_count = len(re.findall(r'"[^"]*"', code))
prefer_double = double_count > single_count
```

#### Naming Convention
```python
snake_case_names = re.findall(r'\b[a-z_][a-z0-9_]*\b', code)
camel_case_names = re.findall(r'\b[a-z][a-zA-Z0-9]*[A-Z][a-zA-Z0-9]*\b', code)
snake_case_ratio = len(snake_case_names) / total_names
```

#### Type Hints
```python
# Count function definitions with type hints
typed_funcs = len(re.findall(r'def \w+\([^)]*:[^)]+\)', code))
total_funcs = len(re.findall(r'def \w+\(', code))
type_hints_ratio = typed_funcs / total_funcs
```

### Incremental Learning (Weighted Average)

```python
# When updating profile
new_weight = 0.3  # 30% from new sample
old_weight = 0.7  # 70% preserve existing

# Example: indent_size update
old_indent = profile.coding_style.indent_size
new_indent = analyze_code_sample(completion_text).indent_size
profile.coding_style.indent_size = int(
    old_indent * old_weight + new_indent * new_weight
)
```

### Privacy & Storage

- **User ID Generation**: `SHA256(vscode.env.machineId).substring(0, 16)`
- **Storage**: `server/data/user_profiles/{user_id}.json`
- **Data Stored**: Only style metrics, NO actual code
- **GDPR**: DELETE endpoint removes file completely
- **Opt-out**: Disable `btl.enablePersonalization` setting

## 🐛 Known Limitations

### Current Limitations
1. **Minimum Data**: Requires 3+ accepted completions before personalization activates
2. **Cold Start**: First few completions are generic
3. **Style Detection Accuracy**: Regex-based, may miss edge cases
4. **No Multi-workspace**: Profile is per machine, not per project
5. **Backend Dependency**: Requires server to be up for profile features

### Potential Future Improvements
- Machine learning for better pattern detection
- Per-project profiles
- Style conflict resolution (mixed styles in codebase)
- Style suggestions ("Your code uses mixed styles, want to standardize?")
